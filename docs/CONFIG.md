# Настройки OgrAi (Game.ini сервера)

Файл: `Insurgency/Saved/Config/LinuxServer/Game.ini` (или `WindowsServer`).
Пишите только то, что хотите изменить — остальное берётся из значений по умолчанию.
Изменения применяются при смене карты / перезапуске сервера.
Единицы расстояния UE: 100 = 1 м.

> Статус: значения по умолчанию проверены в редакторе; чтение из Game.ini проверим
> на сервере при первой упаковке.

```ini
[/OgrAi/Mutators/OgrAi.OgrAi_C]
; --- Профиль восприятия ---
; False — мод не трогает зрение ботов (например, если стоит Improved AI)
bPerceptionProfile=True

; Дальность зрения
SightRangeIdle=15000          ; спокойный бот, 150 м   (ваниль 5000)
SightRangeAlert=30000         ; встревоженный, 300 м  (ваниль 20000)
CloseRangeDist=1000           ; что считается «вблизи», 10 м (ваниль 500)

; Шанс заметить цель: вблизи / на дистанции (дистанция = 150 м)
StandingChanceClose=100       ; (ваниль 100)
StandingChanceDistance=35     ; (ваниль 5)
CrouchedChanceClose=90        ; (ваниль 50)
CrouchedChanceDistance=15     ; (ваниль 2)
ProneChanceClose=60           ; (ваниль 20)
ProneChanceDistance=3         ; (ваниль 0)

; Движение цели повышает заметность
ChanceMovingMultiplier=1.5    ; (ваниль 1.1)
ChanceSprintMultiplier=2.5    ; (ваниль 2.0)

; --- Прочёсывание (BB_Search) ---
; Сколько ботов одновременно идут проверять одну последнюю известную позицию врага
MaxSearchers=2
```

## Запланировано

- Слух (шаги/бег/выстрелы).
- Точность: компенсация разброса на дистанции, подавление.
- Тактика: переключатели подсистем (роли, засады, токены атаки, радио).
- Отладка: вывод в лог.
